## [0.1.0] — 2026-10-10

First tagged release. The template has declared 0.1.0 in `project()` since its first commit; this
tag names a state of the tree rather than introducing new work, so the entries below describe what
the release contains, not what changed since a previous tag.

### Added

- **A starter CNA game**: `HelloGame`, a `Game` subclass with `LoadContent` / `Update` / `Draw`,
  texture loading, `SpriteBatch` drawing, a capability-gated 3D path and keyboard input, under
  `game/`, with a `--smoke-test` mode that draws three frames and exits.
- **CNA's renderer set as data**: `cmake/renderers.json` carries the template-side metadata for
  exactly CNA's **14** public renderers (`SDL_RENDERER`, `SDL_GPU`, `OPENGLES3`, `OPENGL33`,
  `WEBGL2`, `VULKAN`, `WEBGPU`, `METAL`, `HEADLESS`, `SOFTWARE`, `STUB`, `FNA3D`, `DIRECTX11`,
  `DIRECTX9`); `tools/gen_renderer_files.py` cross-checks it against CNA's
  `CNA_RENDERER_PUBLIC_IDENTITIES` and generates `CMakePresets.json` and `docs/renderers.md`,
  and `cmake/CnaRenderers.cmake` refuses an unknown or platform-invalid renderer at configure
  time with an explanation. Selecting a renderer CNA retired is a configure error, not a fallback.
- **Multi-renderer builds**: `CNA_GRAPHICS_RENDERERS` compiles several renderers into one
  binary, validated one by one, with one smoke test per compiled renderer, labelled `headless`
  (no display needed) or `display`; the renderer is chosen at run time through
  `CNA_GRAPHICS_RENDERER` in the environment.
- **Release identity**: `CnaTemplate/Version.hpp`, generated by `cmake/CnaTemplateVersion.cmake`
  from `project(CnaTemplate VERSION ...)` and `CNA_TEMPLATE_VERSION_PRERELEASE`, with
  `CnaTemplate::getVersionString()` and the `CNA_TEMPLATE_VERSION_*` macros; the game's banner
  prints it next to CNA's own version.
- **Required sibling releases**: `cmake/CnaTemplateDependencies.cmake` reads each sibling's
  generated `Version.hpp` after CNA is added and refuses an incompatible checkout (see
  *Dependencies*); `-DCNA_TEMPLATE_CHECK_DEPENDENCY_VERSIONS=OFF` downgrades it to a warning.
- Presets for every renderer of the host platform, packaging for Linux, Windows (MinGW
  cross-build), Web and Android, a CI matrix (`.github/workflows/ci.yml`), and `docs/releasing.md`.

### Changed

- The manifest marks the web as an *experimental* platform of `WEBGPU`, as CNA's own web CI
  builds `WEBGL2;WEBGPU` together under Emscripten through the Dawn port; the browser then needs
  WebGPU. `WEBGL2` remains the only web renderer with a preset.
- `README.md` no longer names the renderers CNA retired; `docs/renderer-build-report.md` and the
  older `NEXT.md` sections are kept as dated history and say so.

### Verification

- `tools/gen_renderer_files.py --check`: the manifest matches CNA 0.1.0's 14 canonical renderers
  and the generated presets and docs are up to date.
- Linux multi-renderer build (`build/`, Release, `OPENGLES3` default plus `OPENGL33`, `VULKAN`,
  `WEBGPU`, `SDL_GPU`, `FNA3D`, `SDL_RENDERER`, `SOFTWARE`, `HEADLESS`, `STUB`): configure
  prints `cna-template: version 0.1.0` and accepts CNA 0.1.0, sharp-runtime 0.1.0, easy-gl 0.1.1
  and meta-gl 0.4.1; 986 steps, 0 errors (the 30 warning lines are CNA's own Release warnings
  from libstdc++ and draco). **11/11** smoke tests: `SOFTWARE`, `HEADLESS` and `STUB` without a
  display, the eight windowed ones on CNA's private GPU runner; the banner reads
  `cna-template 0.1.0 on CNA 0.1.0` and CNA reports `selected at runtime from 10 compiled in`.
  Every windowed renderer was also shown on the real desktop, one window each.
- Web build (Emscripten 6.0.9, `build-probe`, Release, `WEBGL2` default + `WEBGPU`): configure accepts
  all four siblings and warns, as designed, that the web is an experimental `WEBGPU` platform;
  672 build steps, 0 errors; `HelloGame.html/.js/.wasm/.data` produced (wasm 8.5 MB) with both
  renderer identities compiled in. The browser run was not automated (no browser on this host);
  CNA's own web CI builds the same pair.
- Verified on Debian GNU/Linux 13 with GCC 14.2.0, CMake 3.31.6, Ninja, Mesa 25.0.7 and
  Emscripten 6.0.9. Windows (MinGW/Wine), macOS and Android were not repeated at this pin.
